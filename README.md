# 수능 D-Day 계산기

브라우저에서 `index.html`을 열면 바로 실행되는 수능 D-Day 계산기입니다.

- 다가오는 수능까지 남은 날짜(D-Day)와 1교시 시작(08:40)까지의 실시간 카운트다운
- 남은 주 / 주말 / 개월 수, 지난 수능 이후 진행률
- 다가오는 수능부터 10년 뒤 학년도까지 선택, 모의고사 등 원하는 날짜 직접 입력
- 아이디·비밀번호 로그인: 사용자마다 설정이 따로 저장됨 (계정은 이 브라우저의 localStorage에만 저장, 비밀번호는 SHA-256 해시로 보관)

공식 발표된 수능 날짜는 `script.js`의 `OFFICIAL_DATES`에 있고, 발표 전 학년도는 11월 셋째 목요일로 추정해 '예상'으로 표시합니다.
